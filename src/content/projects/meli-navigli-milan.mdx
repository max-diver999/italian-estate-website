## What Should a Navigli Buyer Check Before Reserving?

Navigli is a conversion market rather than a greenfield one, so foreign buyers are underwriting existing fabric. The recurring findings are conformità gaps between the built layout and the cadastral plan, and a condominium regolamento that forbids the tourist use on which a 4% to 5% gross case usually depends.

| Check | Consequence if skipped |
|---|---|
| Conformità edilizia | The gap transfers to the buyer at the rogito |
| Condominium regolamento on tourist use | Can forbid short lets the comune would allow |
| CIN registration | Required before the unit is advertised for tourist use |
| Canal frontage constraints | Landscape rules limit external alteration |

- Settle all 4 before the caparra; none can be fixed by renegotiating price afterwards.
- If short lets are blocked, model a 12-month furnished lease instead: lower gross, materially lower vacancy.
- Budget IMU, set between 0.86% and 1.06% of cadastral value by the comune annually, plus spese condominiali on converted stock.
